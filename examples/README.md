# Illustrative request examples

These are source-audited construction examples, not live API responses. Replace identifiers with actual responses and supply secrets securely in your own process. Do not save JWT/Basic values in .http files. Event times in static examples are illustrative; the Studio generates dates relative to the selected date.

calendar-and-caldav.http covers every public REST and CalDAV contract. calendar.js and calendar.curl illustrate REST, caldav.curl demonstrates discovery and conditional updates, and XML/ICS files provide complete editable protocol bodies. Owner/admin/editor sharing authorization still applies; an owner membership role is not assignable in the current model.
